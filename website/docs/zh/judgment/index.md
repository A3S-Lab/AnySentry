# L1、L2、L3 分层研判与风险分类

AnySentry 把低延迟确定性判断、单事件语义解释和多证据深度调查拆成三个层级。每次升级都携带原始事件、身份、作用域、策略版本和上一层理由，最终结论不会脱离证据链。

## 三个研判层级

| 层级     | 主要职责                              | 输出                                                |
| -------- | ------------------------------------- | --------------------------------------------------- |
| L1 Rules | 识别确定性模式和明确边界，保持低延迟  | `allow`、`warn`、`require_approval`、`block` 或升级 |
| L2 LLM   | 对单次事件补充语义、意图与不确定性    | 结构化风险理由和是否进入 L3                         |
| L3 Agent | 使用受限 Skill 核验多源证据与影响范围 | 带来源的终局允许或阻断结论                          |

## 三类风险审查域

Dashboard 固定展示三类风险域和八个基础风险槽位，即使当前计数为零，用户也能看到系统正在审查什么。

### 系统风险 · 2 项

- 云元数据 SSRF；
- 提权与进程注入。

### 通信风险 · 3 项

- 密钥外泄；
- 提示词注入；
- 异常外联与回连。

### 原子行为风险 · 3 项

- 危险命令执行；
- 凭据文件访问；
- 其他异常动作。

新风险代码不会因为不在基础分类中而被丢弃，而会附加到对应风险域中继续展示。

## 会话与时序上下文

最高风险会话使用六个维度建立画像：命令危险、提示注入、数据泄露、越狱绕过、通信风险和系统性风险。

时序检测以五分钟事件时间窗工作，每个 Agent Session 最多保留八个活动文件候选和六十四条行为事实，并对乱序、重复事件和进程身份做显式处理。时序发现保留为 Shadow 结果，不把时间接近误写成已经证实的攻击。

## 研判边界

- L1 是确定性热路径；
- L2、L3 只有在模型连接与策略就绪后进入对应链路；
- 自然语言判断不能覆盖原始事件；
- 颜色和严重等级不单独决定是否升级；
- 每个结果保留 `eventId`、策略版本、研判层级、理由和延迟。

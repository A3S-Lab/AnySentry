# 四个 AI-Native 安全智能体

AnySentry 不把 AI 放在告警列表之后做摘要，而是让四个受限安全智能体分别进入部署、监控、身份复核和高风险研判节点。它们共享同一证据平面，因此自然语言解释、身份判断和终局结论都能回到具体 Source、Agent、Session 与原子事件。

## 环境发现智能体

环境发现智能体在初始化部署阶段读取主机、工作负载、Workspace、进程树和已有平台标识，识别可能存在的 Agent 与项目边界，并建立首份运行画像。

它可以产生候选身份，但不会把推测直接写成已确认 Agent。稳定身份仍需平台事实、明确标签或人工确认。

## 风险问答助手

风险问答助手位于监控与调查界面。用户可以直接询问当前最高风险、受影响资产、风险变化、判断依据和处置状态。

回答前先绑定系统、Agent、Session、时间窗与风险作用域；回答中的关键结论必须引用事件、拓扑或 Evidence Bundle，不用自然语言覆盖原始事实。

## 身份复核智能体

身份复核智能体把候选 Agent、父子进程、容器或 Pod、Workspace 和行为序列组织为可检查的归因链，帮助审核人员确认其真实身份与运行实例。

人工裁决会记录审核人、理由和时间，并成为后续事件关联的稳定依据。

## L3 深度研判智能体

L3 深度研判智能体只处理高影响、高不确定事件。它使用显式配置的只读安全 Skill 核验攻击意图、行为轨迹、主机指标和影响范围，最终返回允许或阻断结论。

模型连接、Skill、超时、并发和上下文预算都有独立边界；每次事件使用隔离会话，避免一个案件影响另一个案件。

## 共同约束

- 每个智能体只读取完成职责所需的证据；
- 模型结论始终保留来源和研判层级；
- 候选身份和候选规则必须经过明确确认；
- 高影响控制动作进入审计，并由部署组织掌握最终执行权限。

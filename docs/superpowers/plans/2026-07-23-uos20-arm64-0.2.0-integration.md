# AnySentry UOS 20 ARM64 0.2.0 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `anysentry-security-suite-0.2.0-compat3-uos20-arm64.tar.gz`, containing current AnySentry main, Sentry 0.2.0, current Observer main with the verified UOS Linux 4.19.90 legacy backend, bundled Redis, and a transactional first-install/upgrade installer.

**Architecture:** AnySentry and Observer use temporary integration branches based on the last verified UOS build branches. The verified compat2 channel is first imported into Git, then upstream main is merged and conflicts are resolved semantically. Sentry, Node.js, ClickHouse, Redis, Observer, diagnostics, and L3 are assembled into one offline package with exact provenance and target ABI gates.

**Tech Stack:** TypeScript/NestJS, React, pnpm, Rust/Cargo, Aya/eBPF, C, Redis 7, ClickHouse 24.8, Node.js 20, Bash, systemd, Docker cross-build containers, Zig/cargo-zigbuild.

---

## File structure

AnySentry integration worktree:

```text
uos20-arm64/
  build.sh                         release entry point
  versions.env                    immutable dependency and target ABI lock
  lib/common.sh                   repository export, source lock and staging
  scripts/build-*.sh              focused component builders
  scripts/assemble-release.sh     package assembly and provenance
  scripts/verify-release.sh       final offline package gate
  package/install.sh              first install, in-place upgrade and rollback
  package/verify.sh               target runtime acceptance
  package/inspect-host.sh         passive target host report
  package/run-diagnostics.sh      passive and raw BPF diagnostics
  package/systemd/*.service       six-service target topology
  package/config/*                protected environment and database templates
  tests/*.sh                      build and installer contracts
```

Observer integration worktree:

```text
a3s-observer-collector/src/main.rs       current collector runtime
a3s-observer-collector/src/legacy.rs     UOS perf-kprobe legacy adapter
a3s-observer-ebpf-legacy/src/probes.c    Linux 4.19 ARM64 probes
diagnostics/*                            passive and raw syscall diagnostics
scripts/build-uos20-arm64-hotfix.sh      target collector builder
scripts/verify-legacy-bpf-object.mjs     object ABI gate
```

# AnySentry UOS compat8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建包含配置修复、版本化持久日志、资源配额和两份中文发布手册的 UOS 0.2.0 compat8 完整发布包。

**Architecture:** 在现有 UOS 通道内增强事务安装器；配置规范化、现场采集和回滚仍由单一安装事务管理。
systemd 单元承载持久资源策略，发布装配器负责将中文手册和全部运行文件纳入清单。

**Tech Stack:** Bash 5、systemd、Node.js 20、Redis 7.4、ClickHouse 24.8、Markdown。
